# OG-Admin — Standalone Management Suite

Executive management portal for **OG-Supplement** with real-time Socket.IO synchronization, inventory stock controls, and order fulfillment.

## 🚀 Features
- 📊 Executive KPI Dashboard (Live Revenue, Orders, Low Stock Alerts)
- 📦 Product Catalog Manager (Add, Edit, Delete with Instant Client Broadcast)
- 🎛️ Live Inventory Stock Adjuster (1-Click quick adjust `+10`, `+25`, `Zero`)
- 🚚 Order Fulfillment Status Switcher (Update live tracking timelines)
- 👥 Customer Purchase History & LTV Directory
- 🌓 Dark & Light Theme System

## 💻 Local Development
```bash
npm install
npm run dev
```

## 🛠️ Build for Production
```bash
npm run build
```
